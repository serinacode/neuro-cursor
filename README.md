# 🧠 뉴로커서 (NeuroCursor)

**▶ 게임 바로가기: https://serinacode.github.io/neuro-cursor/** (휴대폰·PC 모두 가능)

뇌과학을 잘 모르는 일반인·학생이, 뇌에 심은 전극이 **뉴런 신호만으로 커서를 움직이는 원리**(BCI, 뇌-컴퓨터 인터페이스)를 손가락 하나로 직접 체험하며 이해하는 웹 시뮬레이터예요.

## 어떻게 하나요?
1. 닉네임을 입력하고 **게임 시작** → 가상의 환자 '하늘' 씨 이야기를 봐요.
2. **MISSION 1 신호 해독:** 노란 과녁을 15초 동안 따라가면 디코더가 뉴런 신호를 배워요.
3. **MISSION 2 첫 움직임:** 이제 보라색 커서는 뉴런 신호만으로 움직여요. 연습 과녁 3개를 맞혀요.
4. **MISSION 3 의사소통:** 과녁 하나가 글자 하나! 30초 동안 하늘 씨의 문장을 완성하면 엔딩이 나와요.
5. **보너스 · 둥지 대작전:** 가고 싶은 곳을 가리키며 3D 맵 10단계를 달려 녹투라의 알을 훔치고, 몬스터 50종을 모아요.

## 들어 있는 것
- 뉴런 디코더 (코사인 방향 튜닝 · 포아송 발화 · 리지 회귀)
- 뇌 속 보기(뉴런 지도·집단 벡터·래스터), 전극 수 실험실, 움직이는 그림으로 보는 원리 7단계
- 닉네임별 저장과 이 기기의 플레이어 랭킹
- HTML 파일 하나, 외부 라이브러리·서버·AI API 없음

> 하늘 씨는 가상의 인물이고, 모든 뉴런은 수학 모델로 만든 가짜 데이터예요. 실제 뇌 신호나 개인정보는 쓰지 않아요.
